1. C'est quoi une donnée personnelle ?

Toute info qui permet de t'identifier

Définition : Une donnée personnelle = toute information qui permet d'identifier une personne, directement ou indirectement.

📂 Exemples de données personnelles normales :

👤Nom & Prénom
🏠Adresse
📱Téléphone
🎂Date de naissance
📧E-mail
💼Profession
💡
Ces informations peuvent être enregistrées dans un fichier clients d'une entreprise (ex : Amazon, Fnac, Nike…). C'est pour ça qu'elles doivent être protégées !
🔴

2. Les données sensibles

Celles qui touchent à ta vie privée profonde

Certaines données sont encore plus protégées car elles concernent des aspects très personnels de ta vie :

🌍Origine ethnique
🗳️Opinions politiques
⛪Religion
❤️Orientation sexuelle
🏥Données de santé
🤝Syndicat
🚫
Interdit ! En règle générale, les entreprises n'ont pas le droit de collecter ces données. Exceptions très rares : avec ton consentement explicite, ou pour des raisons d'intérêt public.
🇪🇺

3. Le RGPD

La loi européenne qui protège tes données

RGPD = Règlement Général sur la Protection des Données
C'est une loi européenne (2018) qui oblige toutes les entreprises à protéger tes données.

🏛️ Ce que les entreprises DOIVENT faire :

🎯
Collecter seulement les données nécessaires
🔒
Sécuriser les données collectées
📢
Informer les utilisateurs
✅
Respecter les droits des personnes
💸
Amendes énormes ! Une entreprise qui ne respecte pas le RGPD peut payer jusqu'à 20 millions d'euros ou 4 % de son chiffre d'affaires mondial. Ex : Amazon a eu une amende de 746 millions € en 2021.
🏛️

4. La CNIL

La police française des données personnelles

CNIL = Commission Nationale de l'Informatique et des Libertés
C'est l'organisme français indépendant qui surveille que les entreprises respectent tes droits.

🎯 Ses missions :

🔍Contrôler les entreprises
🛡️Protéger les citoyens
⚖️Sanctionner les abus
📣Informer le public
📞
Tu peux contacter la CNIL si une entreprise ne respecte pas tes droits : cnil.fr ou 01 53 73 22 22. C'est gratuit !
⚖️

5. Tes droits en tant que consommateur

Tu as du pouvoir sur tes propres données !

👁️
Droit d'accès Demander à voir toutes les données qu'une entreprise a sur toi
✏️
Droit de rectification Corriger une donnée incorrecte (ex : mauvaise adresse)
🗑️
Droit à l'effacement Demander la suppression de tes données ("droit à l'oubli")
🚫
Droit d'opposition Refuser que tes données soient utilisées (ex : pub ciblée)
📦
Droit à la portabilité Récupérer tes données pour les transférer ailleurs
